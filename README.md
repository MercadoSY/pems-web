## ⓘ About PEMS-Web

**Poultry Environment Monitoring System (PEMS)** is an IoT-based mobile and web system designed to monitor conditions inside poultry houses, providing poultry workers with an easy and cost-effective way to track and manage their environment.

**PEMS-Web** is designed primarily for **admins** (poultry business owners). It serves as the central hub for high-level oversight, advanced data analytics, report generation, and management of poultry houses, branches, and workers.

## 모 Technology Stack

*   **Frontend**: Vite, React, Bootstrap, Chart.js
*   **Backend & Data**: Firebase (Authentication, Firestore), ThingSpeak
*   **Analysis**: Simple Statistics
*   **Deployment**: Vercel
